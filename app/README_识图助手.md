# 图纸识别助手（本机版）

这个程序只负责：

1. 调用本机 Qwen 视觉服务识别扫描 PDF；
2. 逐页拆分、识别图号/名称/成品代码/类型；
3. 自动合并连续两页图纸，并生成“图号 名称.pdf”；
4. 人工核对后，导出一个独立的“图纸上传包”。

上传包包含：

- `manifest.json`
- `drawings\*.pdf`

导出后，把整个上传包目录交给“图纸上传助手”即可。识别助手不包含 CAXA
上传逻辑，也不需要分发 Qwen。

## 启动

双击 `启动识图助手.bat`。本机需要已有 Python 3.12 和已配置的本地视觉服务。

## 操作

1. 添加扫描件。
2. 按需添加可读原图或 Z03 总装图。
3. 点击“开始识别”。
4. 双击结果行核对或人工补录。
5. 点击“导出上传包”，选择输出目录。
