# 图纸上传助手（分发版）

这个程序只负责读取“图纸上传包”并把图纸上传到 CAXA。它不包含 Qwen、
视觉模型、PDF 识别或整页拆分逻辑。

## 环境

- Windows
- 已安装 CAXA 协同管理 2011 客户端
- 当前用户具备 CAXA 图纸新建/修改权限
- 能访问 CAXA 服务器，默认 `caxa.example.internal:8900`

## 使用

1. 双击 `图纸上传助手.exe`。
2. 二选一准备图纸：
   - 打开识别助手导出的上传包；
   - 或由同事自己拆分、重命名后，直接把 PDF 拖入窗口。
3. 文件名建议严格为“图号 名称.pdf”，例如：
   `01.59.OV.03 焊接管路包.pdf`；单字母工艺文档为 `Z03.xxx.pdf`。
   不符合规则的行会标红并禁止上传。
   如果只是图号/名称字段被手工修改，界面会显示“将按规范文件名上传”，
   程序会把**你选中的那份内容**复制到本任务暂存目录后按规范名上传，
   不会改名或覆盖你的源文件，也不会改用同名的其他旧文件。
4. 填写当前同事自己的 CAXA 用户名和密码。
5. 默认重复图号策略为 `append_iteration`，等同界面中的
   “在现有版本上追加新的版次”。程序会回读版次是否真的增加；没有增加的
   记为“待核实”，不会当成成功。
6. 需要时勾选“上传成功后发起审核打印流程”，审核人默认“审核人”。
7. 点击“上传图纸”。

## 借用与次级条目

- 关系直接显示在“上传图纸”层级树中：
  - CAXA 设计树中**没有**该子件 → 默认“归属子件”（Reference=False）；
  - 设计树中**已有**该子件 → 默认“借用”（Reference=True）；
  - 选中关系行后点击“切换 归属子件 / 借用”可人工勘误，人工选择优先，
    并在本次任务内保持稳定。
- 不再强制 `03.*` 整机下全部借用；文件名前缀也不决定关系类型。
- 借用只链接已经存在的零件；缺父/缺子会逐条显示，**不会新建零件**。
- 先把一批 PDF 全部拖入列表，再在树内把子 PDF 行拖到父 PDF 行上。
  拖动时显示 PDF 拖动标签，经过的上级行高亮，松开后高亮消失。
  也可以右键父级 PDF，选择“增加次级条目”。
- 新建的归属子件会挂到你选定的父级；显式父级不存在会直接报错，不会猜
  另一个父级。
- “执行手动借用”只处理设计树中已经存在的图号；缺失节点会跳过并显示。

## 任务记录、重复提交与待核实

- 每次上传都会在本机写入一个轻量 SQLite 任务日志（默认在
  `%LOCALAPPDATA%\caxa_upload_journal`），记录服务器、账号、文件哈希、
  已确认的 Drawing/版次/关系/流程 ID。
- 同一批内容再次点击上传：不会重复建版次或流程，会提示“该批次已完成”；
  只改关系或只补发流程也不会重传 PDF。需要重新提交时，内容变化或账号/
  服务器变化会自动形成新任务，或在提示里选择“作为新任务重新提交”。
- 超时、helper 退出、写入后回读失败等“结果不明”的操作会标为
  **待核实**，程序不会自动重放。请先在 CAXA 中确认，再用界面按钮
  “核实待定结果”，或命令行：

  ```
  python upload_recover.py list
  python upload_recover.py confirm --task <任务号> --kind upload --key 01.01 --remote-id 123456 --class-id 1002 --iterator 3
  python upload_recover.py no-write --task <任务号> --kind upload --key 01.01 --note "CAXA 中确认未写入"
  ```

  只有被核实的那一条会改变；其它已确认成功不会重做。
- 任一必需关系失败、缺失或待核实时，即使勾选了“发起流程”也不会自动发流程。

## 自动确认重复对话框

- 仅在本次“上传图纸”命令执行期间启用，且只处理**本 helper 进程自己**的
  导入/重复对话框；不会扫描或点击其他 CAXA 窗口。
- 先选中“在现有版本上追加新的版次”并回读勾选状态，确认后才点唯一“确定”；
  选项不明确或多处命中时不点击，改由人工确认。

## 账号安全

密码使用当前 Windows 用户的 DPAPI 加密后写入程序同目录的
`config.json`，不能直接复制到另一台电脑解密。

## 构建（工作设备）

```
powershell -ExecutionPolicy Bypass -File ..\build_all.ps1 -All
```

helper 需 CAXA 2011 引用 DLL，本机会明确报缺依赖；不要用旧 exe 充当新版本。
